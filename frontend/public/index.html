          Limites por camião e turno
          Limites rígidos por turno: o que não couber fica para outro dia. 0 é sem limite.
          Saída antecipada
          Quanto se paga por cada hora que um camião saia antes de o dia começar. A 0, sair mais cedo é grátis.
          Trabalhar de tarde
          Cobrado uma vez a cada camião que trabalhe de tarde, para o plano preferir a manhã. A 0, as duas metades do dia valem o mesmo.
